
这四个核心概念是层层递进的：

**单步奖励 $\rightarrow$ 累积奖励 $\rightarrow$ 状态价值函数 $V$ $\rightarrow$ 动作价值函数 $Q$**

|**符号**|**含义**|**直观理解**|
|---|---|---|
|$r_t$|**单步奖励**|这一步表现怎么样？|
|$G_t$|**累积奖励**|从现在到结束，总体表现怎么样？|
|$V^{\pi}(s_t)$|**状态价值函数**|站在这个状态看，未来大概能拿多少总分？|
|$Q^{\pi}(s_t, a_t)$|**动作价值函数**|在这个状态下，如果采取该动作，未来大概拿多少分？|

---

## 1. 单步奖励 $r_t$

### 定义

$$r_t = R(s_t, a_t, s_{t+1})$$

这是系统在当前步骤给出的即时分数。当你处于状态 $s_t$，采取动作 $a_t$ 并到达下一个状态 $s_{t+1}$ 时，环境会反馈一个奖励 $r_t$。

### 无人机案例

假设无人机当前位置为 $(0,0,2)$，目标在正前方，左前方有障碍物。

- **动作 $a_t$**：向前飞。
    
- **结果**：更靠近目标（加分），但也更靠近障碍物（扣分）。
    
- **最终得分**：$r_t = 3.2$。如果撞击障碍物，则 $r_t = -200$。
    

### 代码实现

在环境的 `step(action)` 函数中体现：

Python

```
# 逻辑组合：奖励 = 进度奖励 - 动作惩罚 - 排斥惩罚
reward = progress_reward - action_penalty - repulsion_penalty
```

## 2. 累积奖励 $G_t$

### 定义

$$G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \dots + \gamma^{T-t} r_T$$

它表示从时刻 $t$ 开始到这局结束，所有折扣后的奖励总和。$\gamma$（Gamma）是**折扣因子**（通常在 0 到 1 之间），代表我们对未来奖励的重视程度。

### 无人机案例比较

1. **策略 1（稳健）**：$G_t = 2 + 0.9(3) + 0.9^2(100) = 85.7$（虽然慢，但最终到达目标）。
    
2. **策略 2（贪婪）**：$G_t = 4 + 0.9(5) + 0.9^2(-200) = -153.5$（前期得分高，但最终撞机）。
    

**结论**：强化学习真正优化的不是单步 $r_t$，而是长期的 $G_t$。

## 3. 状态价值函数 $V^{\pi}(s_t)$

### 定义

$$V^{\pi}(s_t) = \mathbb{E}_{\pi} [G_t \mid s_t]$$

即：如果你处于状态 $s_t$，且之后都按照策略 $\pi$（即 Actor 网络的规则）行动，预期能拿到的总奖励。

### 直观理解

- **局面评估**：$V(s)$ 回答的是“这个局面本身好不好？”
    
- **例子**：如果无人机离目标近且周围空旷，$V(s)$ 很高（约 90）；如果离边界近且障碍物多，$V(s)$ 很低（约 -20）。
    

---

## 4. 动作价值函数 $Q^{\pi}(s_t, a_t)$

### 定义

$$Q^{\pi}(s_t, a_t) = \mathbb{E}_{\pi} [G_t \mid s_t, a_t]$$

即：在状态 $s_t$ 下，**先**强制执行动作 $a_t$，之后再按策略 $\pi$ 行动的预期总收益。

### $V$ 与 $Q$ 的区别

- **$V(s)$**：看“这个局面值多少钱”。
    
- **$Q(s, a)$**：看“在这个局面下，做这个特定动作值多少钱”。
    

### 关系公式

$$V^{\pi}(s) = \mathbb{E}_{a \sim \pi(\cdot|s)} [Q^{\pi}(s, a)]$$

状态价值 = 该状态下所有可能动作价值的平均值（期望）。

---

## 5. 在 TD3 代码中的对应关系

1. **$r_t$ (单步奖励)**：
    
    对应代码：`next_state, reward, done, _ = env.step(action)`。
    
2. **$G_t$ (累积奖励)**：
    
    代码不直接计算完整的 $G_t$，而是通过 **Critic 网络** 学习 $Q$ 值来间接逼近它。
    
3. **$Q(s, a)$ (动作价值)**：
    
    这是 **Critic 网络** 的任务。输入 `state` 和 `action`，输出对应的 Q 值评估。
    
4. **$\pi$ (策略)**：
    
    这是 **Actor 网络** 的任务。输入 `state`，直接输出一个连续的 `action`。
    

---

## 6. 为什么 TD3 重点关注 $Q$ 而不是 $V$？

因为无人机避障是**连续动作控制**任务。

- Actor 输出连续的控制向量（如各轴推力）。
    
- Critic 通过计算 $Q(s, a)$ 来告诉 Actor：“你刚刚选的这个动作，在长期看来是好还是坏”。
    
- Actor 根据 $Q$ 值的反馈不断调整参数，目标是找到能让 $Q(s, a)$ 最大化的动作。
