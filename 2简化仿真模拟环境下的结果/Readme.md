## 子模块说明

### 静态模拟/
基于 Gymnasium 的多智能体无人机配送仿真环境。

**当前状态：已修改为纯规则-based启发式算法空白对照组，没有加载RL训练模型。**

**启动：**
```bash
cd 2简化仿真模拟环境下的结果/静态模拟/
python 结合体.py
```

会弹出 3D matplotlib 窗口，显示：
- 灰色高楼城市场景（1000×1000m）
- 3架无人机（蓝/绿/紫）实时移动
- 金色五角星标记目标位置
- 左上角显示：步数、电量、碰撞次数、与目标距离

### 动态模拟/
动态障碍物环境变体。

### 安全模块/
安全约束增强版本。
