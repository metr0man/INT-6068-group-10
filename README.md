# INT6068 - Neural Networks & Deep Learning
## 3D Drone Path Planning via Reinforcement Learning

### 项目概述

本项目是 **INT6068 - 神经网络与深度学习** 课程的学术研究项目，核心目标是实现基于强化学习的无人机高层路径规划器。

### 项目迭代历程

| 阶段 | 描述 | 状态 |
|------|------|------|
| PyBullet 物理仿真 | 基于 PyBullet 物理引擎的仿真训练 | ❌ 太难且非重点【已弃用】 |
| 简化仿真环境 | 轻量级多智能体仿真，无物理引擎 | ⚠️ 实验性质 |
| **TD3 深度学习** | 自定义 TD3 算法，静态环境训练 | ✅ 核心开发 |
| **最新优化版本** | 优化+3D仿真+曲线收敛+平滑噪声修正 | ✅ 当前重点 |
