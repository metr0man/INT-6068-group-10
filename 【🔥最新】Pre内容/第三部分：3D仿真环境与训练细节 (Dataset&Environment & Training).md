### 一、 PPT 文字大纲 (PPT Outline)

#### **Slide 8: 3D 动态仿真环境构建 (3D Dynamic Environment Building)**

- **拒绝死记硬背 (Preventing Overfitting)**：
    
    - 环境并非静态。每次重置 (Reset) 时，起点和终点坐标均随机生成。
        
- **智能障碍物生成逻辑 (Smart Obstacle Placement)**：
    
    - _挑战_：如果完全随机生成障碍物，可能会直接生成在终点上导致“死局”。
        
    - _解决方案_：在起点与终点连线的 $30\%$ 到 $70\%$ 处，**动态生成 2 个随机半径（如 0.5~1.5米）的球形障碍物**。
        
    - _意义_：迫使无人机真正学会“感知-避障”的泛化策略，而不是单纯记住一条固定轨迹。
        
- **物理碰撞与雷达探测检测**：基于解析几何的精准求交运算（实时计算无人机坐标与球体边界的距离）。
    

#### **Slide 9: 训练数据流与 GPU 并行加速 (Data Flow & GPU Acceleration)**

- **经验回放机制 (Experience Replay)** ：
    
    - 智能体与环境交互产生的数据元组 $(S, A, R, S', Done)$ 被存入容量为 $100,000$ 的 Replay Buffer 中。
        
    - 每次训练从中随机采样 Batch Size = 100 的数据打破数据相关性。
        
- **5000 Episodes 训练数据**：
    
    - 累计进行了 5000 次 Episode 的探索与利用（Exploration vs. Exploitation）。
        
- **硬件级加速 (Hardware Acceleration)**：
    
    - 利用 `torch.device("cuda")` 调用 GPU 显存。
        
    - **张量对齐优化**：在提取 Buffer 数据时，使用 `unsqueeze` 进行维度对齐，将所有的状态、动作批量转化为 Tensor，直接在 GPU 内部完成矩阵运算，极大地缩短了训练时间。

### 二、 演讲讲稿 (Script) - 约 3 分钟

**(Slide 8: 3D仿真环境)**

“除了算法，我们项目的一大特色是**从零手写了整个 3D 物理仿真环境**。在强化学习中，如果环境是固定不变的，神经网络很容易偷懒，退化成‘死记硬背’出一条路。为了训练出真正具有泛化能力的避障模型，我们设计了**动态生成的环境**。

大家可以看屏幕上的生成逻辑：每次回合开始时，起点和终点都是完全随机的。而且，我们没有让障碍物满天乱飞，那样可能产生无解的死局；我们在代码中利用了几何插值，强制在起点到终点连线中间的区域，动态生成两颗半径随机的球形障碍物。这就好像给无人机随机摆了不同的路障，它必须依靠雷达实时探测才能活下来。这种设计极大地提升了模型的鲁棒性。”

**(Slide 9: 经验回放与加速)**

“在训练数据的获取上，我们让无人机在环境中不断试错，累计跑了 5000 个 Episode。

这 5000 局产生的所有‘状态-动作-奖励’数据，都被我们存入了一个巨大的**经验回放池（Replay Buffer）**中。每次网络更新时，我们会从中随机抽取 100 条数据进行 Batch 训练，这有效打破了时间序列上的相关性。

同时，因为 5000 个 Episode 涉及海量的三维空间距离计算和网络反向传播，为了保证训练速度，我们全面启用了 **CUDA GPU 加速**。在处理 Replay Buffer 的数据时，我们利用 PyTorch 的 `unsqueeze` 将数据维度严格对齐，打包成整块的 Tensor 直接送到 GPU 显存里进行矩阵运算。这避免了 CPU 和 GPU 之间频繁的数据搬运，让我们的模型在极短的时间内就能完成数万次迭代。”
